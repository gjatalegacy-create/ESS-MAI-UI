# Provenance and publication changes

Bledar Gjata is the project architect/designer and maintainer. This UI develops the ESS-MAI project independently of its frozen canonical source. The emotional-command contract and supplied visual assets retain their source relationship; publishing the UI does not assert ownership over external datasets.

Implementation and language resources were developed with AI assistance under the author's direction; the author reports reviewing work through shell execution. The fixed supplemental lexicon is model-generated material, not an independent scientific authority. Its source identity, corroboration rules and test fixtures are retained. No claim of independently human-authored code or human validation of every lexical entry is made.

Publication edits only neutralize named-model branding in four comment/header locations and add distribution documentation, license, citation and manifests. Executable Rust/JavaScript statements, persisted source IDs, thresholds and tests are unchanged. Model names inside functional provenance filters, serialized identifiers or test fixtures remain to preserve behavior. The graph index is regenerated from the public-data subset rather than relabeling a restricted index.

See `SOURCE_SNAPSHOT.sha256` for original code/resource hashes and `PUBLICATION_CHANGES.json` for the comment-only differences. `MANIFEST.sha256` identifies the actual files in this distribution. These manifests prove byte correspondence, not independent review.
